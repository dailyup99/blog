## 02 如何修改接口的返回值？

首先，鼠标右键接口，然后选择Override content

![image-20250816000218829](http://139.196.79.103:9001/myimages/imgs/202508160002875.png)

第二步，选择一个目录

![image-20250816000322830](http://139.196.79.103:9001/myimages/imgs/202508160003875.png)

选择完之后就可以修改接口返回值，按住Ctrl+S进行保存

![image-20250816000454342](http://139.196.79.103:9001/myimages/imgs/202508160004384.png)

如果想要撤回，可以删除当前，或者清除所有

![image-20250816000707192](http://139.196.79.103:9001/myimages/imgs/202508160007240.png)

## 03 如何调试el-popover这种弹出框的样式？

浏览器F12，然后输入下面代码，表示3秒过后进入debugger

```javascript
setTimeout(() =>{debugger},3000)
```

然后进入debugger就可以就行调试

## 04 如何界定移动端、iPad和PC？

```javascript
移动端：width < 768
ipad端：width >= 768 && width < 1200
pc端：width >= 1200
```
