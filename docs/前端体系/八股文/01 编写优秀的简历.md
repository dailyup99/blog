## **工作经历 – 忌讳**

工作经历两个忌讳：

- 频繁跳槽
- 空窗期太长

跳槽频率不要超过 3 年 2 跳，5 年 3 跳这样的跳槽频率。如果超过了，建议做以下的优化建议：

1.待的时间很短的和前面的合并；

2.中小城市待过的优化掉，中小城市使用的技术相对落后；

3.将外包公司的经历合并到自研里面；

4.将小型公司的经历合并到大公司里面。

对于空窗期太长的优化建议如下：

1.和前面的工作经历合并起来

- 比如 3 个月之前离职可以说上个月离职，但是这样会带来 2 个问题

  - 社保接不上怎么办？可以说上家公司最后 3 个月，发不起工资了，但是从个人感情来说也想和公司一起渡过难关，所以坚持了 3 个月，但是 3 个月之后，公司依然没有给我交社保，工资也没有给我发，我也没有办法了，所以我选择了离职，现在找工作。
  - 离职证明。可以想办法延长离职证明的时间，实在不行就说 3 个月前发不起工资的时候就已经提了离职证明，但是离职的时候还有一些项目需要接手，当时是以兼职的形式在给公司做项目，但是兼职了 3 个月之后依然没有给我交社保。

  注意：3 个月可以说成 1 个月，但是半年或 1 年就不建议这样做。

  其他的就是说明自己空窗期在做的事情

## **项目经验 – 编写思路总结**

![image-20241005202354103](../../images/202410052023178.png)

**准备八股文要针对简历去准备，而不要一上来就去看 HTML 和 CSS 的面试题。**

**需要花 1 周时间来写简历，再花 1 周左右时间将自己简历中的每个细节进行扩展。**

**简历需要定制化，针对不同公司投递不同的简历。**

## **简历的细节**

**其他信息：教育经历、获得奖项、个人或者开源项目等等**

简历模板：https://www.qmjianli.com/

**简历的整体细节：**

简历长度：尽量保持在 2~3 页（项目经验写 3~4 个即可）

重点一：整个简历要和投递的岗位契合、匹配（技能、业务）

重点二：尽量突出自己的亮点（你有，别人没有）

**简历之外，你需要做的：对自己简历的所有细节，了如指掌！**
