## 15.聊一下 Eventloop，requestIdlecallback 和 requestAnimationFrame的理解

https://www.yuque.com/sohucw/daweiurl/kf5rz2cug0788ruc

JavaScript 是单线程的，采用 **事件循环（Event Loop）** 来执行任务。
任务分为：

- **同步任务**：主线程执行，进入执行栈（Call Stack）。
- **异步任务**：进入任务队列，等待主线程空闲后执行，分为： 

- - **宏任务（Macro Task）**：`setTimeout`、`setInterval`、`setImmediate`（Node.js）、`MessageChannel`、`I/O`、`UI渲染`
  - **微任务（Micro Task）**：`Promise.then`、`queueMicrotask`、`MutationObserver`

执行顺序：

1. 先执行同步任务（主线程任务）。
2. 执行所有微任务（Microtasks）。
3. 执行一个宏任务（Macrotask），然后回到步骤 2。

示例：

```javascript
console.log('start');

setTimeout(() => {
  console.log('setTimeout');
}, 0);

Promise.resolve().then(() => {
  console.log('promise');
});

console.log('end');
```

```javascript
end

setTimeout
```

### `requestAnimationFrame`

- **作用**：在下一帧执行回调，保证动画流畅。
- **优点**：同步浏览器刷新率（通常 60FPS）。
- **用法**：

```javascript

function animate() {
  console.log('Animating...');
  requestAnimationFrame(animate);
}
requestAnimationFrame(animate);
```

## 48.虚拟列表的原理

1. 通过监听滚动事件来确定可视区域位置
2. 计算每个元素的大小，能够在滚动的时候进行快速定位
3. 当用户滚动列表的时候，动态计算并渲染可视区域内的列表项，同时移除或者隐藏不再可见的部分

## 49.webpack如何加速构建速度

1. 首先使用speed-measure-webpack-plugin分析出构建时间，loader耗时，插件耗时等信息
2. babel编译耗时，使用swc工具进行替换
3. loader耗时，配置thread-loader开启多线程并行解析
4. 使用webpack5的持久化缓存技术将模块的编译结果，解析结果缓存到内存中或者文件中
5. 开发阶段去除hash, hash主要是生产环境利用浏览器缓存机制优化用户体验的一种机制，
6. 最后升级老旧的plugin插件，比如升级代码压缩工具terser-webpack-plugin，新的版本底层使用了swc技术来进行多线程压缩

## 50.项目优化思路

1. 压缩资源，比如js,css
2. 图片优化，使用适当的图片格式和压缩算法，对图片进行优化，减少图片大小，提高加载速度。同时使用懒加载技术，延迟加载非首屏可见区域的图片，减少首屏加载时间
3. 延迟加载非关键资源，通过设置script中的属性defer
4. 预加载关键资源，比如css,js文件，可以通过link的rel属性来进行预加载
5. css优化，尽量减少css文件的大小，可以将css文件放在页面头部，尽早加载
6. js优化，将js文件放在页面底部，通过压缩js代码减少js文件大小
7. 服务渲染SSR,  可以减少客户端渲染时间，在传统的客户端渲染中，浏览器需要下载HTML文件，然后执行JavaScript代码来生成并填充页面内容。而在SSR中，服务器会在响应请求时直接生成完整的HTML页面，并包含所需的数据，浏览器只需要下载已经渲染好的HTML，减少了客户端渲染的时间
8. CDN加速，将资源缓存在离用户较近的服务器上，减少网络延迟
