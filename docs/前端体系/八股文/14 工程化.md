## 8.Vite 为什么比 Webpack 快

- **Vite 采用 ES Modules**，按需加载，开发时不用打包。
- **Vite 依赖** `esbuild`，比 `babel` 快 10-100 倍。
- **HMR 更快**，Vite 只更新改动模块，Webpack 需要重构整个依赖图。

## 9.Webpack 打包产物是什么？

- `bundle.js`（合并后的 JS 代码）
- `vendor.js`（第三方库）
- `index.html`（入口文件）
- `assets/`（图片、字体等）

**自己写一个简单的打包器**：

```javascript

const fs = require('fs');
const path = require('path');

function bundle(entry) {
  let content = fs.readFileSync(entry, 'utf-8');
  fs.writeFileSync('dist/bundle.js', content);
}

bundle('./src/index.js');
```

## 10.Webpack 打包优化

1. **Tree Shaking**（去掉无用代码）
2. **Code Splitting**（拆包，懒加载）
3. **使用** `TerserPlugin` **压缩 JS**
4. **缓存（**`cache-loader`**、**babel-loader）
5. **开启** `thread-loader` **并行打包**
