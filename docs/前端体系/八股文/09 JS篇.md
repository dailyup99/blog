## 18.ES Module vs CommonJS

| 特性     | ES Module (`import/export`) | CommonJS (`require/module.exports`) |
| -------- | --------------------------- | ----------------------------------- |
| 语法     | 静态 `import/export`        | 动态 `require()`                    |
| 运行时   | 浏览器/Node.js              | 仅 Node.js                          |
| 作用域   | 只读                        | 可修改                              |
| 加载方式 | 预解析                      | 运行时解析                          |
