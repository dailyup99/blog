## 时间/空间复杂度计算

### 时间复杂度计算

#### 时间复杂度是什么？

一个函数，用大O表示，比如O(1)、O(n)、O(logN)......

定性描述该算法的运行时间

![image-20240512165738497](http://139.196.79.103:9001/myimages/imgs/image-20240512165738497.png)

重点关注1、log2 n、n、n2这 几个

要知道它们之间的大小关系：n2 >n>log2 n>1

O(1)

```javascript
let i = 0;
i += 1;
```

O(n)

```javascript
for (let i = 0; i < n; i += 1) {
  console.log(i);
}
```

O(1) + O(n) = O(n)

```javascript
let i = 0;
i += 1;
for (let j = 0; j < n; j += 1) {
  console.log(j);
}
```

两个时间复杂度相加取增长趋势更快的复杂度。

O(n) * O(n) = O(n ^ 2)

```javascript
for (let i = 0; i < n; i += 1) {
  for (let j = 0; j < n; j += 1) {
    console.log(i, j);
  }
}
```

O(logN)

```javascript
let i = 1;
while(i < n) {
  console.log(i);
  i *= 2;
}
```

### 空间复杂度计算

#### 空间复杂度是什么？

一个函数，用大O表示，比如O(1)、O(n)、O(n^2)......

算法在运行过程中临时占用存储空间大小的量度

O(1)

```javascript
let i = 0;
i += 1;
```

O(n)

```javascript
const list = [];
for (let i = 0; i < n; i += 1) {
  list.push(i);
}
```

O(n^2)

```javascript
const matrix = [];
for (let i = 0; i < n; i += 1) {
  matrix.push([]);
  for (let j = 0; j < n; j += 1) {
    matrix[i].push(j);
  }
}
```

## 数据结构之“栈”

### 栈是什么？

一个后进先出的数据结构

![image-20240512171522534](http://139.196.79.103:9001/myimages/imgs/image-20240512171522534.png)

JavaScript中没有栈，但可以用Array实现栈的所有功能。

```javascript
const stack = [];
stack.push(1);
stack.push(2);
const item1 = stack.pop();
const item2 = stack.pop();
```

在vscode中运行上面的代码，我们并不需要把js引入到html中运行然后浏览器打开。

![image-20240512172648780](http://139.196.79.103:9001/myimages/imgs/image-20240512172648780.png)

只要在第2行打个断点，然后按下F5，就可以看到左边的一些变量信息，重点关注item1、items2和stack的变化。

左上角共有6个按钮，功能分别如下：

第1个按钮点击程序会进入下一个断点，如果没有下一个断点，程序就会执行完。

第2个按钮点击就会一行一行执行代码。

第3个按钮点击，假如当前这会执行了一个函数，就会进入到这个函数当中。

第4个按钮点击，会跳出当前执行的函数。

第5个按钮是重启。

第6个按钮是停止。

### 什么场景下用栈

#### 栈的应用场景

需要后进先出的场景

比如：十进制转二进制、判断字符串的括号是否有效、函数调用堆栈......

#### 场景一：十进制转二进制

后出来的余数反而要排到前面

把余数依次入栈，然后再出栈，就可以实现余数倒序输出。

![image-20240517204927205](http://139.196.79.103:9001/myimages/imgs/image-20240517204927205.png)

#### 场景二：有效的括号

越靠后的左括号，对应的右括号越靠前。

左括号入栈，右括号出栈，最后栈空了就是合法的。

![image-20240517205231614](http://139.196.79.103:9001/myimages/imgs/image-20240517205231614.png)

#### 场景三：函数调用堆栈

最后调用的函数，最先执行完。

JS解释器使用栈来控制函数的调用顺序。

![image-20240517205447555](http://139.196.79.103:9001/myimages/imgs/image-20240517205447555.png)

#### 解题步骤

新建一个栈

扫描字符串，遇到左括号入栈，遇到和栈顶括号类型匹配的右括号就出栈，类型不匹配直接判定为不合法。

最后栈空了就合法，否则不合法。

```javascript
var isValid = function(s) {
  if (s % length === 1) {
    return false;
  }
  const stack = [];
  for (let i = 0; i < s.length; i++) {
    const c = s[i];
    if (s === '(' || s === '{' || s === '[') {
      stack.push(c);
    } else {
      const t = stack[stack.length - 1];
      if (
      	(t === '(' && c === ')') ||
        (t === '{' && c === '}') ||
        (t === '[' && c === ']') 
      ) {
        stack.pop();
      } else {
        return false;
      }
    }
  }
  return stack.length === 0;
}
```

上面的算法还能继续优化，讲到字典的时候再进行优化。

### LeetCode：933. 最近的请求次数

<img src="http://139.196.79.103:9001/myimages/imgs/image-20240517224610848.png" alt="image-20240517224610848" style="zoom:67%;" />

越早发出的请求越早不在最近3000ms内的请求里。

满足先进先出，考虑用队列。

#### 解题步骤

有新请求就入队，3000ms前发出的请求出队。

```javascript
var RecentCounter = function() {
  this.q = [];
}

RecentCounter.prototype.ping = function(t) {
  this.q.push(t);
  while(this.q[0] < t - 3000) {
    this.q.shift();
  }
  return this.q.length;
}
```

## 数据结构之“链表”

### 链表简介

#### 链表是什么？

多个元素组成的列表。

 元素存储不连续，用next指针连在一起。

<img src="http://139.196.79.103:9001/myimages/imgs/image-20240517231211277.png" alt="image-20240517231211277" style="zoom:67%;" />

#### 数组 VS 链表

数组：增删非首尾元素时往往需要移动元素。

链表：增删非首尾元素时，不需要移动元素，只需要改next的指向即可。

#### JS中的链表

JavaScript中没有链表。

可以用Object模拟链表。

```javascript
const a = { val: 'a' };
const b = { val: 'b' };
const c = { val: 'c' };
const d = { val: 'd' };
a.next = b;
b.next = c;
c.next = d;

// 遍历链表
let p = a;
while (p) {
    console.log(p.val);
    p = p.next;
}

// 插入 在c和d中间插入e
const e = { val: 'e' };
c.next = e;
e.next = d;

// 删除 e
c.next = d;
```
