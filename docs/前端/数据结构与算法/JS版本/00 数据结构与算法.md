## 数据结构与算法简介

### 数据结构与算法简介

刷题网站：推荐使用LeetCode。

刷题顺序：推荐按照类型刷题，相当于集中训练。

重点关注：通用套路、时间和空间复杂度分析和优化。

#### 数据结构与算法是什么

数据结构：计算机存储、组织数据的方式，就像锅碗瓢盆。

算法：一系列解决问题的清晰指令，就像食谱。

#### 数据结构与算法的关系

程序 = 数据结构 + 算法

数据结构为算法提供服务，算法围绕数据结构操作。

#### 将要学习的数据结构

栈、队列、链表

集合、字典

树、堆、图

#### 将要学习的算法

链表：遍历链表、删除链表节点。

树、图：深度/广度优先遍历。

数组：冒泡/选择/插入/归并/快速排序、顺序/二分搜索

## 时间/空间复杂度计算

### 时间复杂度计算

#### 时间复杂度是什么？

一个函数，用大O表示，比如O(1)、O(n)、O(logN)......

定性描述该算法的运行时间

![image-20240512165738497](http://139.196.79.103:9001/myimages/imgs/image-20240512165738497.png)

重点关注1、log2 n、n、n2这 几个

要知道它们之间的大小关系：n2 >n>log2 n>1

O(1)

```javascript
let i = 0;
i += 1;
```

O(n)

```javascript
for (let i = 0; i < n; i += 1) {
  console.log(i);
}
```

O(1) + O(n) = O(n)

```javascript
let i = 0;
i += 1;
for (let j = 0; j < n; j += 1) {
  console.log(j);
}
```

两个时间复杂度相加取增长趋势更快的复杂度。

O(n) * O(n) = O(n ^ 2)

```javascript
for (let i = 0; i < n; i += 1) {
  for (let j = 0; j < n; j += 1) {
    console.log(i, j);
  }
}
```

O(logN)

```javascript
let i = 1;
while(i < n) {
  console.log(i);
  i *= 2;
}
```

### 空间复杂度计算

#### 空间复杂度是什么？

一个函数，用大O表示，比如O(1)、O(n)、O(n^2)......

算法在运行过程中临时占用存储空间大小的量度

O(1)

```javascript
let i = 0;
i += 1;
```

O(n)

```javascript
const list = [];
for (let i = 0; i < n; i += 1) {
  list.push(i);
}
```

O(n^2)

```javascript
const matrix = [];
for (let i = 0; i < n; i += 1) {
  matrix.push([]);
  for (let j = 0; j < n; j += 1) {
    matrix[i].push(j);
  }
}
```

## 数据结构之“栈”

### 栈是什么？

一个后进先出的数据结构

![image-20240512171522534](http://139.196.79.103:9001/myimages/imgs/image-20240512171522534.png)

JavaScript中没有栈，但可以用Array实现栈的所有功能。

```javascript
const stack = [];
stack.push(1);
stack.push(2);
const item1 = stack.pop();
const item2 = stack.pop();
```

在vscode中运行上面的代码，我们并不需要把js引入到html中运行然后浏览器打开。

![image-20240512172648780](http://139.196.79.103:9001/myimages/imgs/image-20240512172648780.png)

只要在第2行打个断点，然后按下F5，就可以看到左边的一些变量信息，重点关注item1、items2和stack的变化。

左上角共有6个按钮，功能分别如下：

第1个按钮点击程序会进入下一个断点，如果没有下一个断点，程序就会执行完。

第2个按钮点击就会一行一行执行代码。

第3个按钮点击，假如当前这会执行了一个函数，就会进入到这个函数当中。

第4个按钮点击，会跳出当前执行的函数。

第5个按钮是重启。

第6个按钮是停止。
